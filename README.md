# Pocket Caddie v1.6

## Change
- Moved the New Shot button from the header.
- New Shot now appears directly to the right of Recommend Club.
- No other UI or recommendation logic was changed.

## New Shot behavior
- clears Pin Distance
- clears Required Carry
- resets Adjustment to 0
- clears the previous recommendation
- returns focus to Pin Distance
